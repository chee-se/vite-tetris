# テトリス 実装計画

仕様は [spec.md](./spec.md) を参照。

技術方針：Vite + React + TypeScript、DOM 描画、シンプル回転。

## ディレクトリ構成（予定）

```
src/
├── game/          # React に依存しない純粋なゲームロジック（Vitest でテストする）
│   ├── types.ts
│   ├── tetrominoes.ts
│   ├── field.ts
│   ├── piece.ts
│   └── reducer.ts
├── hooks/         # ゲームループ・キー入力などのカスタムフック
├── components/    # 表示用の React コンポーネント
├── App.tsx
└── main.tsx
```

## ステップ

MVP（遊べるテトリス）は **Step 5 まで**。

| Step | 作るもの | 主に学ぶこと | 状態 |
|---|---|---|---|
| 0 | `create-vite`（react-ts）で雛形を作り、不要なファイルを消す | Vite のプロジェクト構成、`index.html` が入口になる仕組み、dev server | 完了 |
| 1 | 固定データのフィールドを CSS Grid で表示する | ES Modules、HMR、React コンポーネント | 未着手 |
| 2 | ミノを 1 つ表示し、キーで左右・下に動かす | `useReducer`、キーボードイベント、状態と表示の分離 | 未着手 |
| 3 | 衝突判定・シンプル回転 | 純粋関数としてのロジック、**Vitest の導入とテスト** | 未着手 |
| 4 | 自動落下・固定・次のミノの出現 | `requestAnimationFrame` を使ったゲームループ、`useEffect` の後片付け | 未着手 |
| 5 | ライン消去・スコア・レベル・ゲームオーバー | 状態遷移の設計 | 未着手 |
| 6 | NEXT 表示・タイトル / 一時停止画面・見た目の調整 | CSS Modules、静的アセット（`public/` と `import` の違い） | 未着手 |
| 7 | 発展要素（7-bag、ゴースト、ホールド、SRS など） | 好きなものを選んで追加する | 未着手 |
| 8 | ビルドと公開 | `vite build`、`vite preview`、`base` の設定、GitHub Pages へのデプロイ | 未着手 |

## 各ステップの完了条件

- **Step 0**：`npm run dev` で開発サーバーが起動し、ブラウザに最小限の画面が表示される。
- **Step 1**：10 × 20 のフィールドが表示され、ファイルを保存すると HMR で画面が更新される。
- **Step 2**：← → ↓ キーでミノが動く（衝突判定はまだなし）。
- **Step 3**：ミノが壁やブロックを突き抜けない。回転できる。ロジックのテストが通る。
- **Step 4**：ミノが自動で落ち、着地すると固定されて次のミノが出る。
- **Step 5**：ラインが消え、スコアが増え、積み上がるとゲームオーバーになる。
